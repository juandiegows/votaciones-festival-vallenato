Cómo hacerlo

  1. Descarga la plantilla y llena las hojas «Edición», «Categorías», «Votaciones» y «Opciones».
  2. Borra la fila de ejemplo de cada hoja.
  3. Súbela aquí. Si alguna fila tiene un error no se crea nada y verás la hoja y la fila que debes corregir.

Qué se crea

  • La edición queda cerrada (no visible al público) salvo que marques «Activarla al importar».
  • Las votaciones se crean como borrador: revísalas y publícalas desde el panel.
  • Las URL amigables vacías se generan desde el nombre o el título.
  • Imágenes, íconos propios y audios se suben después desde cada formulario.
  • Para copiar una edición, expórtala con «Exportar → Plantilla de Excel con los datos», cambia el año y súbela.

Cómo leerlo. Las cajas en 3D son nodos (hardware o entornos de ejecución); dentro van los componentes de software y los artefactos que se despliegan. Las líneas son rutas de comunicación con su protocolo. En local, docker compose up levanta los mismos contenedores web (:8095), api (:8096) y db (:3317), sin Cloudflare ni edge_nginx.
